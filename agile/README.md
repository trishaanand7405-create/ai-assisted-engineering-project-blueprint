# Agile

> **The operating framework for iterative product delivery.**

This folder defines the Agile practices used throughout the **AI-Assisted Engineering Project Blueprint**.

The documents here establish a common way of working for all project teams, regardless of whether the team is developing an AI/ML application, intelligent data pipeline, multi-agentic pipeline or Digital Twin.

## The Core Cycle

```text
PLAN
  ↓
BUILD
  ↓
TEST
  ↓
REVIEW
  ↓
RETROSPECT
  ↓
ADAPT
  ↓
NEXT SPRINT
```

## Working Principle

The Agile framework is intentionally **lean**.

Teams should use only the processes, meetings and documentation that create real value.

> **People collaborate. Products evolve. Feedback drives change. Quality remains everyone's responsibility.**

The objective is not to learn Agile terminology.

**The objective is to experience Agile product engineering.**
