## 16. Definition of Done

The story is Done when:

* [ ] Implementation is complete.
* [ ] Acceptance Criteria are satisfied.
* [ ] Relevant tests pass.
* [ ] Code has been reviewed where required.
* [ ] Documentation has been updated where required.
* [ ] Known limitations are documented.
* [ ] Required evidence is available.

---

## 17. Story Readiness

Before implementation:

* [ ] The user is understood.
* [ ] The problem is clear.
* [ ] The expected value is understood.
* [ ] Acceptance Criteria are sufficiently clear.
* [ ] Dependencies are known.
* [ ] Important assumptions are visible.
* [ ] The story is appropriately sized.
